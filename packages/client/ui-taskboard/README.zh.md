# @deepseek-ai/dsh-client-ui-taskboard

[English](README.md) | 中文

## 概述

Web 任务工作台在原生主面板中展示项目和任务。可登记工作目录、编辑需求与验收标准、查看任务活动。

<a id="use-this-package"></a>
## 使用此包

从 Web 侧栏打开**任务工作台**。填写绝对路径或通过目录选择器添加项目。在看板与列表之间切换，搜索任务或按状态筛选。拖动卡片可排序，也可将符合条件的任务移至**待办**。启动窗口显示 SDK 的 Provider 和模型。部署启用了 Codex 或 Codely 时，可以在此选择。每次原生执行均启动新会话，所选执行器会写入本次 Run 的启动授权。入队前如有变更，请重新打开启动窗口确认；Run 历史保留本次选择。点击当前或历史 Run 的**已保存的输入**，可以查看原始需求、反馈和当次所选文件内容。创建或编辑任务时可设置**风险等级**。启动窗口和已保存的 Run 输入会显示该版本的等级。创建或编辑任务时，可在**约束**中填写执行限制。任务详情保留当前及历次需求的约束和评论。再次启动或查看已保存的输入时，展开**前序执行的恢复位置**，可核对来源 Run、Session、需求版本、输入回执和最后观察到的事件。在**已保存的输入**中展开**启动授权**，可查看执行器、路线选择、授权范围、时间和命令 ID。选择**快速任务 · v1**可直接执行；选择**常规任务 · v1**可按执行顺序填写步骤，也可留空。启动窗口与已保存的输入显示该修订选定的工作流。

在当前或历史 Run 展开**原生工具活动**，可查看执行器报告的分类计数。空摘要表示适配器未观察到工具或权限事件。没有已保存摘要的 Run 不显示此项。

选择**里程碑计划 · v1**，每行填写一个阶段目标。在**开始执行**窗口核对本次阶段。点击**接受阶段交付**后，可单独启动下一阶段。退回后可再次执行原阶段。最后一个阶段点击**接受交付**后任务完成。

点击**下载任务说明**可将所选 Run 的需求、选入文件内容、执行目录、基线提交和已记录的授权保存为 JSON。

恢复备份后，选择**继续原会话**可使用原 SDK Session 文件。要开启新 Session，请选择**原目录**或**新工作树**，为本次 Run 重新选择材料后确认。任务历史保留此前的 Run。

注册项目时勾选**交付前检查 Git 已跟踪的变更**，交付页会显示 Host 实际检查的结果。检查失败或未执行时，接受前需填写理由。交付页单独显示 Host 是否请求了模型审查，人工决定在提交后显示。

注册 npm 项目时可选择**项目验证脚本**。启动窗口显示本次选定的脚本；提交交付时由 SDK 执行。验收页显示结果与可用的退出码。接受失败或未确认的检查时须填写理由。

注册项目时选择**自定义 npm 脚本**或**自定义 pnpm 脚本**，填写 package.json 中的脚本名，开始执行时确认页面显示的命令。

打开**待办**任务，确认目录后将 Run 加入队列。**执行设置**显示已配置的 SDK 路线。执行区显示进展、连接状态及停止操作。通过**待我处理**打开等候回答或工具审批的任务。

在任务详情的**任务关系**中设置父任务和前置任务。要等待人工验收后自动运行一次，请选择**新工作树**，勾选单次授权并加入队列。开始前可在 Run 区域取消。

打开交付以查看验证证据与文件变更。已经验收的交付会显示人工决定、时间、反馈及逐项豁免理由。填写所需的豁免理由后可接受交付，也可填写反馈退回给下一次执行。将待验收任务拖入**已完成**会打开交付验收。项目检查显示状态、记录时间，以及可用的退出码或无法执行的原因。点击**下载审查摘要**，可将本次交付的验收覆盖、已记录风险和项目检查结果保存为本地 JSON。Host 提供审查模型时，点击**请求模型审查**可向页面显示的模型发送该摘要。交付页显示每次请求的状态及返回的意见。操作者仍可接受或退回交付。

点击**用此审查意见起草退回反馈**可编辑建议。**退回修改**将任务移回待办；通过**开始执行**单独授权一次修复，再验收新交付。

通过**备份与恢复**导出选定项目，或在活动 Run 退出后下载工作台备份。在空工作台选择文件并点击**恢复备份**。结果显示未包含的 Session 日志数和已取消的排队 Run 数。

在选定项目打开**团队权限**，输入账号名称并选择初始角色，在对话框内复制签发的密钥。成员在自己的浏览器会话打开成员登录页并粘贴密钥。编辑出现版本冲突时，先复制要保留的草稿，刷新任务，再提交修改。在另一个项目中可为已有账号选择角色，也可移除当前项目授权。

<a id="model-experience"></a>
## 模型体验

无，因为任务工作台面板只展示记录，并将操作者命令传给[工作台控制器](../../api/taskboard-controller/README.zh.md)。

#### KV Cache effect

浏览器面板不追加模型请求内容。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 执行设置显示部署指定的 SDK 路线。模型和权限校验在启动 Run 时进行。

<a id="dev-note"></a>
### 开发备注

此包向现有侧栏和主面板注册内容，并从工作台 Remote API 读取数据。客户端没有独立的权威任务状态，因此不发布不变量 companion。
