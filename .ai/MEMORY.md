## Built-runtime plugin loading

- Type stripping loads `.ts` plugins: the built `dsh` CLI imports `.ts` profile plugins through Node 22.18 native type stripping, so constructor parameter properties (`constructor(private readonly x: T)`) fail with `Type stripping does not support parameter properties`; declare the fields and assign them in the body. Type-only imports from package sources are erased and stay safe. Verification: bridge fixture boot loop on 2026-11-02, [PoC checkpoint](tasks/dsh-web-provider-poc/handoff.md).
- Patch plugin paths: in a `--patch` entry list, an `insert[].name` starting with `.` resolves against the patch file's own directory; absolute `file://` names fail to import in the built runtime. Generate run patches where the relative path to the plugin is stable. Verification: same bridge boot loop on 2026-11-02.

- Exact Host export review: `@deepseek-ai/dsh-home-paths#defaultDshHome` is duplicate-install-safe because it returns an OS-default primitive path without shared instance state or effects; the user explicitly approved that export only. Future state/identity changes require renewed review. Other exports are not covered. [Current owning decision](../.agents/notes/implemented/process/2026-08-26-published-dependency-faces.md#exact-default-home-path-export), [two-copy artifact evidence and approval](tasks/dsh-p1-publication-hygiene/evidence/host-export-review.md); verified 2026-11-15.

- Local attempt budgets: the optional request-budget-policy owns one atomic receipt record per immutable allowance ID. Known pre-delegation cancellations release slots; delegated, crashed or unknown attempts remain charged. Synchronous admission stays mounted while asynchronous storage initializes, and storage setup must not block its cancellation hooks. Live rules use one Volatile snapshot; stale initialization cannot republish readiness. Verification: owner coverage, real profile/Settings, plain-Node dsh Host overlap/crash/restart and keyless Session scenarios on 2026-11-15. [Owner](../packages/guard/request-budget-policy/README.md), [evidence](tasks/dsh-p1-local-request-budget/handoff.md). Optional per-Session caps count the same fresh receipts for an exact durable ID within one allowance, including all intents and auxiliary calls; missing identity refuses before native dispatch, while read-only preparation remains Session-independent. Resuming an ID retains charges; a fork or child with another ID shares only the overall allowance. [Session-cap evidence](tasks/dsh-p1-session-request-budget/handoff.md), verified 2026-11-15. Official balances, token/currency budgets and Task caps remain separate work.

- Whole-application storage drain: direct root-fiber disposal can start sibling cleanups concurrently and remove consumers from registry discovery before their cleanup settles. `disposeApplication` in app-boot awaits every before-dispose hook before resource teardown; the budget owner aborts/drains receipts there. For ordinary provider withdrawal, yield the service disposer and resource disposer from one ordered effect; calling `ctx.provide` without yielding leaves a separate fiber effect. Verification: provider-write barrier, actual built-dsh SIGTERM settlement, and app drain/failure tests on 2026-11-15. [Lifecycle decision](../.agents/notes/implemented/architecture/2026-08-22-single-dsh-application-launcher.md#shutdown-ownership), [evidence](tasks/dsh-p1-local-request-budget/handoff.md).

- Configured admission activation: an invalid initial plugin configuration can fail before the plugin installs its own admission listener. App-boot therefore requires enabled paid-route-policy/request-budget-policy packages or imported policy namespaces to activate independently of entry ids and refuses inference before the startup audit while they are inactive. Direct embedders must enforce the same requirement. Verification: both policy namespace unit cases and a built-dsh invalid-budget custom-id process case with zero native adapter entry on 2026-11-15. [Launcher decision](../.agents/notes/implemented/architecture/2026-08-22-single-dsh-application-launcher.md#launch-scope), [fixed-source evidence](tasks/dsh-p1-local-request-budget/handoff.md).

- Built-consumer sequencing: root `doc-typecheck`, `lint` and `typecheck` first run `build:lib:host`; standalone `doc-sync` includes that wrapper. They may temporarily remove/rewrite CLI and package artifacts. Complete those producers before running real SDK/subprocess consumers or artifact negative controls; the corresponding `:contracts-ready` commands consume an already coordinated build. Source: root package scripts and run-gates; verified by [SDK execution evidence](tasks/dsh-p1-preparation-records/handoff.md), 2026-11-15.
- Settled native request accounting: optional token-meter/request-records appends one metadata-only event per observed native dispatch settlement and exposes a bounded replay view. The existing Session ID plus committed seq identifies a record; no second transcript or request UUID is needed. Captured source survives registration replacement. Optional loopAttempt links native records to the committed step/start seq and step-local attempt ordinal; enclosing Session identity keeps resumed attempts distinct. Lifecycle-local LlmAttemptId remains unsuitable as a durable key. [Attribution/restart evidence](tasks/dsh-p1-request-attempt-link/handoff.md). Completed-Turn UI sources join only this explicit identity through Step Location data; legacy, duplicate and mismatched evidence stays unknown, independently of current model discovery. [UI/native Web evidence](tasks/dsh-p1-turn-usage-source/handoff.md). Optional TokenUsage.measurement preserves explicit provider-reported/estimated counters; absent metadata stays unknown, never inferred from usageSource. Native accounting cache3 rebuilds old caches, and Turn details distinguish mixed/partly unknown samples. Direct DeepSeek requires observed raw input/output fields, including zero; pi-ai/SIWC remain unclassified. [Measurement and SDK negative-control evidence](tasks/dsh-p1-usage-measurement/handoff.md), verified 2026-11-16. These counts do not establish official billing or balance; native preparation failures now have a separate audit/projection and never increment settlement counts. Other outer middleware refusals, process death before settlement and nonlocal Sessions remain outside coverage. [Preparation audit evidence](tasks/dsh-p1-preparation-records/handoff.md), [Owner reference](../packages/llm/token-meter/README.md#request-records), [verified profile/SDK and negative-control evidence](tasks/dsh-p1-usage-records/handoff.md), verified 2026-11-15.

- Native replay outlet: llm-replay without a providers catalog uses the catch-all llm/stream waterfall and bypasses registered llm/dispatch hooks. Native policy/accounting tests must register explicit replay providers and exact model capability metadata. Frozen V3 accepts only its recorded event vocabulary: keep old inputs unchanged and author new accounting events only in current V4, without expanding the released codec. [Replay owner](../packages/test-support/llm-replay/README.md#mounting-it), [evidence](tasks/dsh-p1-usage-records/handoff.md), verified with native headless/TypeScript/Python SDK scenarios on 2026-11-15.

- Native request consent ordering: optional paid-route-policy ask mode reuses existing approval audit and scoped UI answerers; llm/authorize runs before dispatch reservations, and invocation-local checkBeforeDispatch callbacks recheck permission immediately before native construction. A revoked preset must not become implicit consent merely because ask mode remains enabled. Rejection/unavailable/cancelled questions never enter dispatch accounting or local budget receipts. [Owner](../packages/guard/paid-route-policy/README.md), [regression and actual Web/SQLite evidence](tasks/dsh-p1-paid-route-interactive/handoff.md), verified 2026-11-16.

- macOS SDK scope evidence: a graphical user launchd job allocates a resource coalition whose membership survives reparenting and process-group changes. Its kernel active count can outlive both the SDK root and the relay. Retain a lease until the exact coalition reports zero and the job is unloaded. Verified on macOS 15.6.1 with the authenticated Web Host and a detached tool process. [SDK contract](../packages/sdk/client/README.md#errors-and-teardown), [real scope evidence](tasks/dsh-tboard-03/evidence/macos-launchd-scope.json).

An input attempt records the earliest possible Session sequence before sending, which prevents a reused Session's previous identical prompt from matching. [Owner](../packages/api/taskboard-controller/README.md), [authenticated Web restart evidence](tasks/dsh-tboard-08/evidence/macos-session-restart.json).
