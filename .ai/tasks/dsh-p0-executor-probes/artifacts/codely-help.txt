Usage: codely [options] [command]

 Codely - Launch an interactive CLI, use -p/--prompt for non-interactive mode

Commands:
  codely                       Launch Codely CLI  [default]
  codely mcp                   Manage MCP servers to extend Codely capabilities with external tools and services
  codely extensions <command>  Manage codely-cli extensions.
  codely skills <command>      Manage agent skills.  [aliases: skill]
  codely commands <command>    Manage custom commands.  [aliases: command]
  codely agents <command>      Manage agents.  [aliases: agent]
  codely update                Check for Codely CLI updates and install if available.  [aliases: upgrade]
  codely serve                 Run built-in servers (e.g. Unity MCP server, Web UI)

Options:
  -m, --model                                Model  [string]
      --multimodal                           Multimodal model to use for image/video analysis  [string]
      --flash                                Flash model to use for internal operations and as the fallback target  [string]
      --disable-next-speaker-check           Disable next speaker checks and automatic continuation prompts  [boolean]
      --default-agent-model                  Default model for subagents. Overrides the main model for all task-spawned agents unless the agent definition specifies its own model.  [string]
  -p, --prompt                               Prompt. Appended to input on stdin (if any).  [string]
  -i, --prompt-interactive                   Execute the provided prompt and continue in interactive mode  [string]
  -s, --sandbox                              Run in sandbox?  [boolean]
      --sandbox-image                        Sandbox image URI.  [string]
  -d, --debug                                Run in debug mode?  [boolean] [default: false]
  -a, --all-files                            Include ALL files in context?  [boolean] [default: false]
      --all_files                            Include ALL files in context?  [deprecated: Use --all-files instead. We will be removing --all_files in the coming weeks.] [boolean] [default: false]
      --show-memory-usage                    Show memory usage in status bar  [boolean] [default: false]
      --show_memory_usage                    Show memory usage in status bar  [deprecated: Use --show-memory-usage instead. We will be removing --show_memory_usage in the coming weeks.] [boolean] [default: false]
  -y, --yolo                                 Automatically accept all actions (aka YOLO mode, see https://www.youtube.com/watch?v=xvFZjo5PgG0 for more details)?  [boolean] [default: false]
      --approval-mode                        Set the approval mode: default (prompt for approval), auto_edit (auto-approve edit tools), yolo (auto-approve all tools), plan (read-only planning mode)  [string] [choices: "default", "auto_edit", "yolo", "plan"]
      --telemetry                            Enable telemetry? This flag specifically controls if telemetry is sent. Other --telemetry-* flags set specific values but do not enable telemetry on their own.  [boolean]
      --telemetry-target                     Set the telemetry target (local or gcp). Overrides settings files.  [string] [choices: "local", "gcp"]
      --telemetry-otlp-endpoint              Set the OTLP endpoint for telemetry. Overrides environment variables and settings files.  [string]
      --telemetry-log-prompts                Enable or disable logging of user prompts for telemetry. Overrides settings files.  [boolean]
      --telemetry-outfile                    Redirect all telemetry output to the specified file.  [string]
  -c, --checkpointing                        Enables checkpointing of file edits  [boolean] [default: false]
      --experimental-acp                     Starts the agent in ACP mode  [boolean]
      --resume                               Resume from checkpoint by tag: return history first, then initialize session in background (use with --experimental-acp).  [string]
      --continue                             Resume the most recent conversation for the current project (interactive mode).  [boolean] [default: false]
      --resume-session, --resumeSession      Resume a previous interactive session by session ID (non-ACP mode).  [string]
      --resume-path, --resumePath            Restore a resumable checkpoint/session JSON file by path for this process only (non-ACP mode).  [string]
      --experimental-skills                  Enable experimental Skills feature  [boolean] [default: true]
      --experimental-goal                    Enable the experimental /goal feature (long-running goal tracking with optional token budget). Off by default to keep the tool catalog and prompt-cache prefix unchanged for users who do not use it.  [boolean] [default: false]
      --experimental-memory                  Enable the experimental structured memory system (read_memory/append_memory/update_memory tools, forge injection, and /memory). Off by default; hierarchical CODELY.md loading into the system prompt remains unchanged.  [boolean] [default: false]
      --skills                               Limit enabled skills to the provided list (skills are enabled by default). Supports comma-separated values or repeated --skills flags.  [array]
      --allowed-mcp-server-names             Allowed MCP server names  [array]
  -e, --extensions                           A list of extensions to use. If not provided, all extensions are used.  [array]
  -l, --list-extensions                      List all available extensions and exit.  [boolean]
      --list-jobs                            List all jobs across all sessions for the current project and exit.  [boolean]
      --proxy                                Proxy for gemini client, like schema://user:password@host:port  [string]
      --include-directories                  Additional directories to include in the workspace (comma-separated or multiple --include-directories)  [array]
      --path-policy                          Path boundary policy. "strict": workspace-only. "read_bypass": unrestricted reads. "read_write_bypass": unrestricted reads and writes.  [string] [choices: "strict", "read_bypass", "read_write_bypass"]
      --default-ignore                       How the built-in heavy-directory ignore list (node_modules, .git, build outputs, etc.) is applied during CODELY.md memory discovery. "none": never (default; relies on gitignore). "backup": only when the project has no effective .gitignore (e.g. SVN/plain folders). "merge": always, unioned with gitignore.  [string] [choices: "none", "backup", "merge"]
      --respect-gitignore                    Whether CODELY.md memory discovery honors .gitignore. When omitted, memory discovery keeps its historical default (off). Set true to also exclude gitignored directories during the scan.  [boolean]
      --prewarm                              Start a prewarmed (cwd-unbound) ACP agent: complete the runtime/module bootstrap and ACP connection, but defer cwd-bound config/memory work until the first session is opened. Used to hide cold-start latency.  [boolean]
      --prewarm-workspace                    Prewarm bound to a specific workspace directory: like --prewarm but also runs that workspace's config/memory discovery up front, so the first session in that workspace is ready immediately.  [string]
      --openai-logging                       Enable logging of OpenAI API calls for debugging and analysis  [boolean]
      --openai-api-key                       OpenAI API key to use for authentication  [string]
      --openai-base-url                      OpenAI base URL (for custom endpoints)  [string]
      --wire-api, --wire_api                 Model wire API to use (chat|responses|messages)  [string] [choices: "chat", "responses", "messages"]
      --reasoning_effort, --reasoningEffort  OpenAI reasoning_effort for reasoning/compatible models (minimal|low|medium|high|xhigh|max)  [string] [choices: "minimal", "low", "medium", "high", "xhigh", "max"]
      --enable_thinking, --enableThinking    OpenAI-compatible extension: set chat_template_kwargs.enable_thinking (omit field when not provided)  [boolean]
      --enable_reasoning, --enableReasoning  Alias of --enable_thinking: set chat_template_kwargs.enable_thinking (omit field when not provided)  [boolean]
      --extra_body, --extraBody              OpenAI-compatible extra_body as a JSON object string (merged into request body)  [string]
      --tavily-api-key                       Tavily API key for web search functionality  [string]
      --searxng-url                          SearXNG instance URL for web search  [string]
      --example-prompt                       Load and execute an example prompt from the example-prompts folder (non-interactive mode only)  [string]
      --list-example-prompts                 List all available example prompts  [boolean] [default: false]
      --list-tools                           List all available built-in tools  [boolean] [default: false]
      --cmd                                  Execute a slash command (e.g. "/model list") without starting the interactive UI. The leading "/" is optional.  [string]
      --exclude-tools                        Exclude specific tools for this session (does not modify settings)  [array]
      --agents                               Enable or disable the agents system  [boolean] [default: true]
      --auto-edit-memory                     Allow the model to automatically edit memories (append/update). Use --no-auto-edit-memory to restrict to manual edits only.  [boolean]
      --agent                                Start the session with a default selected agent (subagent) name. Requires agents to be enabled.  [string]
      --output-format                        Output format for responses  [string] [choices: "text", "json", "stream-json"] [default: "text"]
      --autosave-filename                    Use the specified base filename for autosave and related export artifacts.  [string]
      --auth-type, --auth                    Authentication type to use. Requires CUSTOM_AUTH for non-default providers.  [string]
      --upm                                  Enable automatic Unity Package Manager (UPM) connection at startup (use --no-upm to disable)  [boolean] [default: true]
  -v, --version                              Show version number  [boolean]
  -h, --help                                 Show help  [boolean]
