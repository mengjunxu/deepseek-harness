# P1-07 原生 Run 工具与权限活动

当前和历史 Run 的「原生工具活动」展示关联执行器实际报告的类别和计数。工具状态与权限答复分别记录。SDK 在原生执行器返回之后、解析交付之前将摘要提交给持有该 Run 租约的 Host。摘要只含固定类别的正整数计数。中断可能发生在上报之前，此时历史页不显示摘要。历史数据缺省该字段时同样可读。适配器回调只接收匹配 Session 或 thread/turn 的事件。

macOS 上的实际 Codex 写入报告一次命令、一次完成。内部拒绝升级时没有发出可见的工具或审批事件，工作树保留基线。Codely 对两次写入均报告一次未细分类工具调用，允许场景报告允许和完成，拒绝场景报告拒绝和失败。经过 Web Host 重启和空库备份恢复，计数仍归属原 Run，所有交付均等待人工验收。备份的执行器不匹配时会拒绝恢复。模型端点均在本机回环。

三个相关单测文件 166/166，通过的 Web Codex 回归为 3/3。两个独立安装各通过原生派发、写入与拒绝。定向编译、lint、文档配对和 Git 空白检查通过。全仓 doc-sync 37/42，五类既有问题记录在[日志](log.md)。[实测结果和包摘要](evidence/local.json)。

修改涉及两个原生适配器、subagent 单次执行观察接口、Taskboard SDK/Host/历史页、测试夹具、相应说明和生成文档。分支与本地远端跟踪引用提交差为零，本步和此前工作树变更均未提交或推送。对应设备和草稿 PR 仍按用户安排待验。本次授权仅用于继续开发，未修改共享额度规则、架构决策或长期记忆。

下一项是独立核验原生会话续接能力。工作台目前仅允许新开原生会话。接手时先查正式适配器对持久会话身份和恢复的支持，再设计重启后能区分旧会话与新建会话的验收。Codex 已释放本步写入权。
